Key Project: DeepDaily (AI Learning Platform)

I built DeepDaily, an AI-powered learning platform that generates structured, day-by-day learning experiences for any topic.
It is a full-stack system designed to move beyond generic AI responses and deliver guided, personalized learning journeys.

The platform is live at: https://deepdaily.net/

DeepDaily combines:

A modern Next.js frontend (React + TypeScript) with a clean, responsive UI optimized for long-form learning
A FastAPI backend designed for structured AI workflows and streaming responses
A custom multi-agent architecture built from scratch to orchestrate learning generation
Real-time streaming of AI-generated lessons using Server-Sent Events (SSE)
Persistent user data and curriculum tracking

Agent-Based Architecture

A core part of DeepDaily is its custom AI agent system, designed to simulate how a human would structure learning over time.
The system includes:

Planner Agent
Generates a full multi-day curriculum based on topic, level (beginner/intermediate/advanced), and duration

Daily Lesson Agent
Produces structured lessons for each day, including explanations, examples, and exercises

Resource Discovery Agent
Enriches each lesson with curated external resources (articles, videos, documentation) using web search

Evaluator Agent
Ensures consistency, quality, and progression across the generated curriculum

This architecture allows DeepDaily to generate coherent, progressive learning paths instead of isolated answers.
