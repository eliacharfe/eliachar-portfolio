Key Project: Multi-LLM Chat Platform

I built a full-stack multi-provider AI chat platform designed as a production-style architecture (not a simple demo chatbot).

The platform includes:

A premium Next.js frontend (React + TypeScript) with a responsive, modern chat UI
A Dockerized FastAPI backend with streaming responses via Server-Sent Events (SSE)
Firebase Authentication (Google + email/password) with server-side token verification
PostgreSQL persistence for chats and messages, isolated per user_id
Multi-provider model routing with provider normalization and scalable configuration

It supports per-user chat history, streaming token-by-token responses, model selection, markdown rendering, chat previews, and a clean multi-chat management experience.
